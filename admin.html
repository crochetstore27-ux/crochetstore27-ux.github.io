Sin conectar

Para publicar cambios necesitas tu "llave" de GitHub. Solo se pide una vez en este celular o computadora. Sin la llave puedes probar todo, pero no publicar.

¿Cómo saco mi llave? (paso a paso)
  1. Abre este enlace (con tu cuenta de GitHub abierta).
  2. En Token name escribe: Panel tienda
  3. En Expiration elige la fecha más lejana que te deje (o "No expiration").
  4. En Repository access marca Only select repositories y elige tu repositorio.
  5. En Permissions → Repository permissions → busca Contents y cámbialo a Read and write.
  6. Baja y toca Generate token. Copia el código largo que empieza con github_pat_ y pégalo aquí abajo.

🔒 No compartas esa llave con nadie. Se guarda solo en este dispositivo.
