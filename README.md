# Lizzy Store · Página de crochet

Página de la tienda: **https://crochetstore27-ux.github.io**
Panel de administración: **https://crochetstore27-ux.github.io/admin.html**

## ¿Cómo agrego productos?
1. Abre el panel (`/admin.html`).
2. La primera vez pega tu "llave" de GitHub (el panel explica paso a paso cómo sacarla).
3. En **Subir catálogo PDF** elige tu PDF. La página lee nombres, precios y fotos.
4. Revisa, corrige lo que haga falta y toca **Agregar al catálogo**.
5. Toca **🚀 Publicar en mi página**. En 1 o 2 minutos se ve el cambio.

También puedes cambiar precios, fotos, esconder o borrar productos en **Mis productos**, y tu WhatsApp, Instagram y textos en **Datos del negocio**.

## ¿Qué hay en cada carpeta? (para el futuro)
- `index.html`, `css/styles.css`, `js/app.js`: la tienda.
- `admin.html`, `css/admin.css`, `js/admin.js`: el panel.
- `data/products.json`: la lista de productos. `data/config.json`: datos del negocio.
- `img/productos/`: fotos de los productos.
- `vendor/`: lector de PDF (pdf.js) y lector de texto en imágenes (Tesseract), incluidos para que todo funcione sin depender de otros sitios.

Todo es gratis: GitHub Pages aloja la página y el panel guarda los cambios directamente en este repositorio.
